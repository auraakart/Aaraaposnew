# AaraaPOS

AaraaPOS is an offline-first, AI-assisted point-of-sale and business-management platform designed first for Indian small and medium businesses.

## Product promise

A first-time shop employee should be able to start billing within 5–10 minutes, while owners retain rigorous controls, auditability and business insight.

## Engineering principles

- Simple surface, rigorous financial core
- Offline-first critical operations
- Server-enforced tenant isolation and RBAC
- Immutable financial history with reversals/corrections
- Modular monolith before microservices
- Deterministic billing/tax/payment logic; AI is optional assistance
- Low infrastructure and operational cost

Development is organized through `develop` and short-lived feature branches. `main` is reserved for stable, release-quality code.
